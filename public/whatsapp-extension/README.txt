HOW TO INSTALL IN CHROME (Takes 30 seconds):
1. In Google Chrome, open a new tab and go to: chrome://extensions
2. In the top-right corner, turn ON "Developer mode".
3. Click the "Load unpacked" button in the top-left.
4. Select this folder ("whatsapp-extension").
5. Done! Now whenever you click "Mark Ready" in RSCC Admin, it will automatically find your ALREADY OPEN WhatsApp Web tab, open the customer chat, and paste the message into that exact same tab! Zero new tabs!
